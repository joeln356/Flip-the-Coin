# DevChallenges.io - Flip The Coin

Uma aplicação web simples e interativa para simular o lançamento de uma moeda (cara ou coroa), desenvolvida como solução para o desafio "Flip The Coin" da plataforma [devChallenges.io](https://devchallenges.io/).

![Thumbnail for the Flip The Coin coding challenge](./thumbnail.jpg)


## Funcionalidades

- Lançamento aleatório de moeda com animação fluida de rotação 3D
- Resultado imediato: **Cara** ou **Coroa**
- Design **responsivo** e mobile-first
- Interface limpa, moderna e intuitiva
- Implementação leve usando apenas tecnologias nativas (sem frameworks)

## Tecnologias Utilizadas

- HTML5
- CSS3 (animações e transições)
- JavaScript (Vanilla) – lógica de aleatoriedade e manipulação do DOM
